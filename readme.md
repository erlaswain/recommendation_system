# 🍿 Рекомендательная система фильмов «Октябрь»

Программный модуль персональных рекомендаций фильмов и сериалов с интерактивным веб-интерфейсом. Алгоритм анализирует историю оценок пользователя и с помощью матричного разложения прогнозирует его интерес к непросмотренным картинам.

## 🛠 Стек технологий

* **Язык:** Python 3

* **Анализ данных и математика:** Pandas, NumPy, SciPy (алгоритм сингулярного разложения разреженных матриц SVD)

* **База данных:** SQLite (хранение каталога, пользователей и истории оценок)

* **Веб-интерфейс:** Streamlit

* **Интеграция:** REST API (KinopoiskDev) через `requests`

## ✨ Ключевые возможности

* **Система профилей:** Регистрация и авторизация пользователей, личный кабинет с историей оценок.

* **Математическое ядро (Коллаборативная фильтрация):** Быстрый расчет персональных рекомендаций на лету.

* **Динамический контент:** Подгрузка актуальных обложек и описаний фильмов через внешнее API.

* **Оптимизация:** Автоматическое кэширование ответов от сервера для ускорения отклика интерфейса.

## 🚀 Как запустить проект локально

**1. Склонируйте репозиторий:**

```
git clone https://github.com/ВАШ_ЛОГИН/recommendation_system.git
cd recommendation_system

```

**2. Установите зависимости:**

```
pip install -r requirements.txt

```

**3. Настройте API-ключ:**
Для подгрузки постеров и описаний фильмов используется API Кинопоиска (KinopoiskDev). В репозитории ключ удален в целях безопасности.
Откройте файл `api_utils.py` и вставьте ваш личный API-ключ в переменную:

```
API_KEY = "ВАШ_КЛЮЧ"

```

*(Примечание: Если ключа нет, приложение перехватит ошибку и подставит локальные заглушки вместо постеров, работоспособность системы при этом сохранится).*

**4. Инициализируйте базу данных:**
Для первоначального создания структуры таблиц SQLite и загрузки стартового каталога выполните скрипт:

```
python init_db.py

```

**5. Запустите веб-приложение:**

```
streamlit run app.py

```

Интерфейс рекомендательной системы автоматически откроется в вашем браузере по адресу `http://localhost:8501`.
